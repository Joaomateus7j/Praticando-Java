# ☕ Praticando Java do Zero

Bem-vindo ao meu espaço de treinos com a linguagem Java! Este repositório nasceu da necessidade de ter um ambiente totalmente isolado para testar lógicas, resolver desafios extras e criar meus próprios projetos de fixação.

## 🧠 Meu Foco Atual
* Dominar os fundamentos do Java puro.
* Escrever códigos limpos e bem estruturados.
* Integrar o fluxo de desenvolvimento com Git e GitHub de forma profissional.

## ⚙️ Tecnologias e Ferramentas
* **Linguagem:** Java (JDK 26)
* **IDE:** IntelliJ IDEA
* **Controle de Versão:** Git / GitHub Desktop

## 🛠️ Organização das Práticas
As soluções estão separadas por pastas temáticas dentro do diretório `src`:
* 📁 `variaveis` -> Exercícios envolvendo tipos de dados e operadores.
* 📁 `condicionais` -> Desafios de estruturas de controle e tomadas de decisão.
